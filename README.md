# OneCRabbit

COM-библиотека, через которую 1С читает и отправляет сообщения в RabbitMQ. Платформа 1С не подключает пакет `RabbitMQ.Client` напрямую, поэтому библиотека регистрируется в Windows как COM-объект `OneCRabbit.Client` и вызывает клиент RabbitMQ изнутри.

Сообщение можно получить и не снимать с очереди, пока 1С его явно не подтвердит. Тело сообщения читается и пишется в UTF-8 или Windows-1251.

## Что нужно на сервере 1С

- Windows.
- 1С:Предприятие 8.3 той же разрядности, что и библиотека.
- .NET Framework 4.8 или 4.8.1. В Windows 10 начиная с версии 1903 и в Windows 11 он уже есть.
- Доступ к серверу RabbitMQ.

## Установка

Готовой папки в репозитории нет: `dist` не хранится в git. Её получает тот, кто клонировал проект и собрал библиотеку.

На компьютере с .NET SDK:

```bash
git clone <адрес-репозитория>
cd OneCRabbit
dotnet build src/OneCRabbit/OneCRabbit.csproj -c Release -f net48
dotnet build src/OneCRabbit/OneCRabbit.csproj -c Release -f net48 -p:Net48Platform=x86
```

После сборки появляются две папки:

- `dist` — для 64-битной 1С;
- `dist/x86` — для 32-битной 1С.

На сервер 1С копируется вся нужная папка, вместе с `OneCRabbit.dll`, `RabbitMQ.Client.dll` и остальными dll. Затем от имени администратора:

```powershell
cd C:\OneCRabbit
.\register-com.ps1
```

В конце должно появиться `Зарегистрировано: OneCRabbit.Client`. Если код 1С выполняется на сервере, регистрация нужна на сервере.

## Пример для 1С

Полный подписанный пример лежит в `examples/usage.bsl`. Аргументы COM передаются по порядку, поэтому в примере у каждого аргумента своя переменная.

```bsl
Клиент = Новый COMОбъект("OneCRabbit.Client");

ИмяПодключения = "1c";
КодировкаЧтения = "windows-1251";
КодировкаЗаписи = "utf-8";
Хост = "rabbit.example.com";
Порт = 5672;
Пользователь = "guest";
Пароль = "guest";
ВиртуальныйХост = "/";
ИмяОчереди = "orders";
ЧислоСообщений = 0;
ТегПотребителя = "orders-1c";

Клиент.SetConnectionName(ИмяПодключения);
Клиент.SetReadEncoding(КодировкаЧтения);
Клиент.SetWriteEncoding(КодировкаЗаписи);
Клиент.Connect(Хост, Порт, Пользователь, Пароль, ВиртуальныйХост);

Клиент.DeclareExisting(ИмяОчереди);
Клиент.SetPrefetch(ЧислоСообщений);
ТегПотребителя = Клиент.Subscribe(ИмяОчереди, ТегПотребителя);

Пока Истина Цикл
    Сообщение = Клиент.Receive();
    Если Не Сообщение.HasMessage Тогда
        Прервать;
    КонецЕсли;

    Текст = Сообщение.Body;
    Клиент.Ack(Сообщение.DeliveryTag);
КонецЦикла;

Клиент.Unsubscribe();
Клиент.Disconnect();
```

`Receive` только забирает сообщение в 1С. С очереди оно снимается после `Ack`. `Nack(Метка, Истина)` возвращает сообщение в ту же очередь. `Move(Метка, "archive")` перекладывает исходные байты в другую очередь.

Кодировка по умолчанию — UTF-8. Если в очереди Windows-1251, перед чтением нужен `SetReadEncoding("windows-1251")`. Для отправки в Windows-1251 используется `SetWriteEncoding("windows-1251")`.

## Методы

| Метод | Назначение |
|---|---|
| `SetConnectionName(Имя)` | Имя соединения в RabbitMQ. Вызывать до `Connect` |
| `Connect(Хост, Порт, Пользователь, Пароль, ВиртуальныйХост)` | Открыть соединение и канал |
| `SetReadEncoding(Кодировка)` | Кодировка байтов, которые уже лежат в очереди |
| `SetWriteEncoding(Кодировка)` | Кодировка байтов при `Publish` |
| `DeclareQueue(Очередь)` | Создать устойчивую очередь |
| `DeclareQueueType(Очередь, Тип)` | Создать очередь типа `classic`, `quorum` или `stream` |
| `DeclareExisting(Очередь)` | Проверить уже существующую очередь, не меняя её аргументы |
| `SetPrefetch(Число)` | Сколько сообщений забирать. `0` — все, максимум `65535` |
| `Subscribe(Очередь, ТегПотребителя)` | Подписка без автоматического подтверждения |
| `Receive()` | Следующее сообщение из буфера |
| `Ack(Метка)` | Подтвердить и снять с очереди |
| `Nack(Метка, ВернутьВОчередь)` | Отклонить. `Истина` возвращает в ту же очередь |
| `Move(Метка, Очередь)` | Переложить исходные байты и подтвердить исходное сообщение |
| `Publish(Очередь, Текст)` | Отправить текст в очередь |
| `PublishTo(Обменник, Ключ, Текст)` | Отправить текст в обменник |
| `GetMessage(Очередь)` | Забрать одно сообщение и сразу подтвердить |
| `Unsubscribe()` | Снять подписку |
| `Disconnect()` | Закрыть соединение |

У полученного сообщения есть свойства `HasMessage`, `Body`, `DeliveryTag`, `ConsumerTag`, `Exchange`, `RoutingKey` и `Redelivered`.

## Проверка без 1С

Проект `OneCRabbit.Console` вызывает те же методы из командной строки. В Rider его нужно назначить запускаемым проектом. После запуска доступны команды `help`, `connect`, `use`, `subscribe`, `receive`, `ack`, `read-encoding` и `write-encoding`. Файлы для регистрации в 1С собираются командами из раздела «Установка».
